## How to provide downloads to the project
1. Add the chosen Free items to your personal Fab library while logged in.
2. Download via Fab / Epic Games Launcher, or export original FBX files if provided.
3. Upload the pack ZIP to this ChatGPT conversation (if you want me to inspect it).
4. For local private Unreal workspace: unpack FBX assets in ExternalAssets/<pack>/.
5. With Unreal installed, run Scripts/import_local_fab_fbx.py within the editor.
6. Confirm imported path names, collision, LOD settings, textures and device performance.
7. To use the actual meshes in gameplay, replace placeholder geometry / components
   with approved assets through editor and C++ changes.
